# kSQL Dashboard Pro — デモアプリ一式

Qiita の連載「**表示タイプ別 実践ガイド**」(KPI カード / データ表 / グラフ / マークダウン)で使うデモアプリ、投入データ、ダッシュボード設定の一式です。

記事のとおりの画面を、ご自身の kintone 環境で再現できます。

## 中身

| フォルダー | 内容 |
| :--- | :--- |
| `templates/` | kintone アプリテンプレート **1 本**(3 アプリ同梱) |
| `scripts/` | データ投入スクリプト。**2 ファイルで 1 組** |
| `settings/` | ダッシュボードの設定 JSON 5 本 |

## 必要なもの

| | |
| :--- | :--- |
| kintone | 公式対応ブラウザの最新版(PC) |
| プラグイン | rex0220 kSQL Dashboard Pro |
| 権限 | アプリテンプレートの読み込みに **kintone システム管理者** |
| Node.js | **18 以上**。データ投入スクリプトに使う |

**npm install は要りません。**スクリプトは依存パッケージを持たず、Node の標準機能だけで動きます。

## 手順

### 0. プラグインを入れておく

テンプレートは売上明細アプリでプラグインを**有効にした状態**で作られています。先に kSQL Dashboard Pro をインストールしておいてください。

### 1. アプリを作る

1. **kintone システム管理 → 「アプリテンプレート」→「読み込む」** で `templates/rex0220-ksql-demo1.zip` を読み込みます

   > システム管理者の権限が要ります。持っていない場合は、管理者に読み込みだけ依頼してください。アプリの作成自体は一般ユーザーでもできます

2. **「アプリを作成」→「テンプレートから作成」** で `rex0220-ksql-demo1` を選びます

**テンプレートは 1 本で、3 アプリが一度にできます。**

| アプリ | 役割 |
| :--- | :--- |
| 売上明細 | 主役。約 1,500 件を入れる |
| 月次目標 | 担当者 × 年月の目標。達成率で使う |
| 商品分類マスタ | 3 階層の分類。階層の展開で使う |

フィールドの型・重複禁止・ドロップダウンの選択肢・ユーザー選択、それに記事で使う**カスタマイズ一覧 5 本**まで入った状態でできます。

**プラグインの設定は入っていません。**アプリ番号が焼き付いた SQL を配らないためです。設定は手順 3 で取り込みます。

### 2. データを入れる

**テンプレートにレコードは含まれません。**スクリプトで入れます。

```bash
# 認証(どちらか)
export KINTONE_BASE_URL=https://xxxxx.cybozu.com
export KINTONE_USERNAME=your-login
export KINTONE_PASSWORD=your-password

cd scripts

# 下見。通信せず、何件どう入るかの要約だけ出す
node load-demo-data.mjs --app 4239 --goal 4240 --master 4241

# 実行
node load-demo-data.mjs --app 4239 --goal 4240 --master 4241 --users your-login --apply
```

`--app` などには**ご自身の環境のアプリ番号**(URL の `/k/4239/` の部分)を入れます。

| 引数 | 意味 |
| :--- | :--- |
| `--app` / `--goal` / `--master` | 3 アプリのアプリ番号 |
| `--users` | ユーザー選択に入れるログイン名。カンマ区切りで複数 |
| `--apply` | これが無いと下見(通信しません) |
| `--clean` | 既存レコードを全削除してから入れる |
| `--end YYYY-MM-DD` | 「今日」の代わりに使う基準日 |

**日付は実行日から逆算して作られます。**「今月」「先月」のペインが常に動くようにするためです。裏返すと、**日をまたいで入れ直すと数字が変わります**。同じ数字を保ちたいときは `--end` を固定してください。

### 3. ダッシュボードを取り込む

1. アプリの設定 → プラグイン → kSQL Dashboard Pro
2. **ツール → インポート** で `settings/` の JSON を選ぶ
3. 確認ダイアログの「**アプリ番号の変換**」に、ご自身の環境のアプリ番号を入れる

> SQL 中の `APP4239` などはここで自動的に置き換わります。**JSON を手で書き換える必要はありません。**

一覧の割り当ても自動です。テンプレートに `【型別】KPI` などの一覧が入っており、取り込みは**一覧名で照合**します。

| 設定 JSON | 対応する記事 | 一覧 |
| :--- | :--- | :--- |
| `型別-KPI-見本.json` | KPI カード編(8 ペイン) | 【型別】KPI |
| `型別-表-見本.json` | データ表編(3 タブ 10 ペイン) | 【型別】表 |
| `型別-グラフ-見本.json` | グラフ編(3 タブ 14 ペイン) | 【型別】グラフ |
| `型別-マークダウン-見本.json` | マークダウン編(5 ペイン) | 【型別】マークダウン |
| `型別-ダッシュボード-見本.json` | 4 つの型を組み合わせた見本 | 【型別】ダッシュボード |
